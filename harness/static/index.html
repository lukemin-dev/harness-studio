작업 도우미 사용

새 작업에서 분석·PostgreSQL 문법 전환·검수 양식을 선택하고 대상 파일을 입력하세요. 지시 채우기를 누르면 초안이 작성됩니다. 내용을 확인하고 등록한 후 실행하세요. 분석·검수 보고서 경로는 프로젝트의 허용 파일에 추가해야 합니다.

01 · 저장소 연결

커밋이 있는 로컬 Git 저장소를 선택하세요. 실제 실행은 현재 HEAD의 별도 작업 폴더에서 시작합니다. 미커밋 변경이 있으면 먼저 정리해야 합니다.

02 · 범위와 완료 기준

수정 허용 패턴과 검사 명령을 설정합니다. 예: src/main/resources/mapper/**/*.xml. 명령은 인자 배열로 입력하며 셸 문자열로 실행하지 않습니다.

03 · 수정과 독립 검수

수정 담당은 workspace-write, 검수 담당은 read-only로 실행합니다. 자동 검사가 실패하거나 검수 지적이 있으면 설정한 횟수 내에서 다시 수정합니다.

04 · 결과 확인과 반영

변경 파일·diff·검사 결과를 확인하세요. 결과는 별도 작업 폴더에 보존됩니다. 원본으로 자동 병합하거나 원격 저장소에 푸시하지 않습니다.

완료 상태의 의미

‘소스·검사 통과’는 등록한 명령과 소스 검수를 통과했다는 뜻입니다. 실제 DB·화면 검증을 수행한 증거가 없으면 시스템 전환 완료로 보고하지 않습니다.

로컬 운영 범위

신뢰할 수 있는 본인 저장소와 명령만 등록하세요. 검사 명령은 내 PC 권한으로 실행됩니다. 자격 증명·개인정보를 작업 지시나 로그에 넣지 마세요. 로그와 작업 폴더는 로컬 데이터 폴더에 저장됩니다.

프로젝트 연결

예: [["{python}", "-m", "unittest", "-v"]]. {python}은 현재 Python으로 대체됩니다.

새 작업

양식은 지시 초안입니다. 대상·완료 기준을 확인한 뒤 등록하세요. 분석·검수는 보고서 저장 경로도 허용 파일에 등록해야 합니다. 등록만으로 실행되지는 않습니다.
