# 원격 대화에서 하네스 사용

전제: 공식 원격 연결로 이 PC에서 실행되는 대화에 연결되어 있어야 합니다.
이 기능은 기기 연결을 만들거나 인증을 대신하지 않습니다.

## 사용자 흐름

1. 원격으로 연결한 대화에서 프로젝트와 원하는 작업을 말합니다.
2. 도우미가 프로젝트의 허용 파일·검사 명령을 확인합니다.
3. 제목·작업 지시·완료 기준을 정리하여 하네스에 대기 작업으로 등록합니다.
4. 기존 실행 절차에서 권한과 정책 검사를 거칩니다.
5. 실행된 작업의 기록을 확인하여 실제 검사 결과와 미검증 항목을 보고합니다.

예: “공통코드 XML을 분석하는 작업으로 등록해줘. 구조는 유지하고 DB2는 제외해.”

등록은 실행 성공을 뜻하지 않습니다. 기존 정책 거부를 다른 경로로 재실행하는 용도로
이 기능을 사용하지 않습니다. 원격 연결에서도 기존 제한이 그대로 적용됩니다.

## 도우미용 로컬 도구

하네스 폴더에서 Python으로 `-m harness.bridge status`를 실행하여 상태를 확인합니다.
등록은 `-m harness.bridge register <작업 JSON 파일>`입니다.
JSON에는 `project_id`, `title`, `prompt`, `acceptance`를 문자열로 지정합니다.
프로젝트 ID는 상태 조회로 확인하며 추측하지 않습니다.
개인정보나 비밀번호를 작업 지시에 포함하지 않습니다.
작업 파일은 Git에서 제외되는 `.harness` 아래에 보관합니다.

연결 주소는 로컬 PC로 한정됩니다. CSRF 검사를 유지하며 자동 실행·자동 재시도·
자동 push는 하지 않습니다. 등록 중 연결이 끊기면 먼저 상태를 확인해 중복 등록을 피합니다.

이 패치는 실제 집 기기와의 연결 또는 EDMS AI 실행 성공을 검증한 것이 아닙니다.
